# GapResearchEN

**English integrated skill · Version 1.0.0**

From an initial interest or uploaded papers to topic alternatives, traceable literature synthesis, defensible potential research gaps, and a feasible **Research Design and Roadmap**.

This package combines the topic discovery and evidence discipline of GapResearch 1.1.0 with the beginner guidance, method selection and engineering design checks of MetodİnşasıMüh 1.2.0. It is an integrated adaptation, not a line-by-line translation or a replacement for either Turkish repository.

## Start with or without papers

Examples:
- “I need an undergraduate capstone topic in mechanical engineering. I have one semester and no laboratory access.”
- “I want a master's thesis topic in education but do not know which methods to use.”
- “Use these papers to map the evidence and investigate potential research gaps for a journal article.”
- “Audit this simulation study's verification and validation plan.”

The skill first establishes the intended deliverable, unless already stated. It accepts “I don't know,” explains options, compares varied topics and scales expectations to the degree, output and resources.

## Use as a skill

Place the complete `gapresearch-en` folder in the skill location supported by your AI environment, or upload it using that environment's custom-skill interface. Keep SKILL.md, references and templates together. Installation steps and persistence vary by platform; reading a GitHub link does not automatically install a skill.

## Use as a prompt

Copy the complete `PromptUsage.txt` into a new chat. It contains the main instructions and all four supporting references as one self-contained prompt. Installation is unnecessary; paste it again for a new chat. The CSV templates are optional record formats for prompt use.

## Files

- SKILL.md: routing, common workflow and quality rules.
- references/topic-discovery.md: profiles, alternatives and selection.
- references/evidence-workflow.md: search, extraction, synthesis and gap validation.
- references/method-quality.md: method-specific checks, including engineering.
- references/output-structures.md: roadmap and evidence-report structures.
- templates/: English record schemas.
- PromptUsage.txt: standalone prompt equivalent.
- LICENSE and ATTRIBUTION.md: source attribution and retained license.

## Scope and access

Supports capstones, master's and doctoral theses, journal articles, reviews, funding proposals, conference papers and technical reports across disciplines. Detailed engineering checks apply when relevant; this is not a dedicated legal, medical or other professional-advice skill.

Search depth depends on connected tools and lawful access. The skill does not provide database subscriptions. Without browsing, it offers labeled preliminary ideas and a search plan. A topic suggestion is not proof of novelty, and a proposed study is not a completed result.
